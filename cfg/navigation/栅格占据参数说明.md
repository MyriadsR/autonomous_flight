这些是**射线投射（Raycasting）概率建图**的核心参数，基于**贝叶斯占用栅格地图更新算法**：

## 工作原理

当传感器发射一条射线并探测到障碍物时：
- 射线路径上的栅格：概率**降低**（认为是空闲）
- 射线终点的栅格：概率**提高**（认为是占用）

## 参数详解

### **`raycast_max_length: 5.0`**
- **射线投射最大长度**：5米
- 从传感器位置发出的射线最多追踪5米
- 超过5米的空间不会被更新
- **作用**：限制计算范围，提高效率；5米是深度相机的有效探测距离

### **`p_hit: 0.70`**
- **命中概率**：0.70（70%）
- 当射线在某个栅格处探测到障碍物时
- 该栅格的占用概率会**增加**到70%
- **含义**：传感器说"这里有障碍物"的可信度
- 不设为1.0是因为传感器有误差，保留不确定性

### **`p_miss: 0.35`**
- **未命中概率**：0.35（35%）
- 当射线**穿过**某个栅格但没有在此处探测到障碍物
- 该栅格的占用概率会**降低**到35%
- **含义**：传感器说"这里是空的"的可信度
- 不设为0.0是因为可能有透明物体或传感器盲区

### **`p_min: 0.12`**
- **最小占用概率阈值**：12%
- 栅格占用概率 < 12% → 认定为**空闲**（Free）
- **作用**：清晰划分空闲区域，低于此值确信没有障碍物
- 用于路径规划时判断可通行区域

### **`p_max: 0.97`**
- **最大占用概率阈值**：97%
- 栅格占用概率 > 97% → 认定为**占用**（Occupied）
- **作用**：清晰划分障碍物区域，高于此值确信有障碍物
- 用于碰撞检测和避障

### **`p_occ: 0.80`**
- **占用判定阈值**：80%
- 栅格占用概率 > 80% → 在可视化或规划时视为**障碍物**
- 介于 p_min 和 p_max 之间的是**未知区域**（Unknown）
- **作用**：在规划时的保守判定，比p_max更早触发避障

## 概率更新示例

假设某个栅格初始概率为0.5（未知）：

```
第1次射线穿过未命中 → 0.5 × (0.35/0.5) = 0.35
第2次射线穿过未命中 → 0.35 × (0.35/0.5) ≈ 0.24
第3次射线命中障碍物 → 0.24 × (0.70/0.5) = 0.336 → ... (多次命中后) → 0.85
```

## 三种状态判定

```
占用概率 < 0.12  → 空闲（Free） - 可以飞过去
0.12 ≤ 概率 ≤ 0.97 → 未知（Unknown） - 需要探索
概率 > 0.97      → 占用（Occupied） - 必须避开
```

其中 **p_occ (0.80)** 作为规划时的安全阈值：
- 概率 > 0.80 就开始避障（更保守）
- 概率 > 0.97 才是完全确定的障碍物

## 调参建议

- **提高 p_hit**：对传感器更信任，障碍物判定更快（可能误报）
- **降低 p_miss**：更快清除障碍物（动态环境）
- **降低 p_occ**：更保守的避障策略（安全第一）
- **提高 p_min**：更积极探索未知区域
